# Tech Soban AI Portfolio

This repository contains the AI portfolio website for Muhammad Soban Sarmad.

## Overview

- **Home page**: `index.html`
- **Contact page**: `Pages/contact.html`
- **Projects page**: `Pages/projects.html`
- **Project details**: `Project_Details/`
- **Assets**: images in `About_Images/` and `Projects_Screenshots/`, videos in `Project_Videos/`

## Features

- AI portfolio showcasing machine learning, computer vision, and full stack projects
- Chatbot assistant embedded on the home page
- Contact form powered by Formspree
- SEO enhancements with metadata, `robots.txt`, and `sitemap.xml`

## Deployment

This site is designed to deploy on GitHub Pages. If the repository is published to GitHub Pages under a project scope, the base URL should be `https://<username>.github.io/<repo-name>/`.
